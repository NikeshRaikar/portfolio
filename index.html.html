TTxB (ceT-logger) — Dual-Channel Bus Logger

A high-throughput, hardware-synchronized dual-channel CAN FD and Automotive Ethernet (100BASE-T1 / 1000BASE-T1) logging appliance built on Raspberry Pi 5. Engineered for deterministic timestamping, zero-drop trace capture, and effortless deployment as a native .deb package on GitHub.

DISTRIBUTED HARDWARE ARCHITECTURE

Cross-Border Remote ECU Test Bench

An intercontinental HIL bridging architecture connecting automotive CAN FD and Automotive Ethernet test benches between Germany and India over encrypted, low-latency L2/L3 network tunnels—enabling distributed engineers to run real-time UDS/DoIP diagnostics and automated regressions on physical ECUs remotely.

Engineering from first principles

Bridging low-level automotive bus physics with scalable software test automation and reproducible Linux infrastructure.

Engineering Philosophy

Modern vehicle architectures demand verification pipelines that are as deterministic as the embedded ECUs they validate. I design end-to-end test frameworks that eliminate manual bottlenecks—combining protocol-level precision (UDS, DoIP, CAN FD, DLT) with clean Python automation, Debian-packaged edge tooling, and continuous hardware-in-the-loop (HIL) execution.
